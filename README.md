# NewsReaderApp (Android)

App Android sviluppata in Kotlin e Jetpack Compose che aggrega notizie da feed RSS ed estrae in locale il testo completo e le relative immagini dall'articolo originale, mostrando il link alla fonte solo al termine della lettura.

## Compilazione automatica su GitHub
1. Carica tutti i file di questo repository nel branch `main`.
2. Vai nella scheda **Actions** del repository.
3. Attendi il completamento del workflow **Build Android APK**.
4. Scarica l'artefatto **NewsReader-APK** dalla sezione **Artifacts** ed estrai `app-debug.apk`.
